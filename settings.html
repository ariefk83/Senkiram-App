Pengaturan

Konfigurasi fitur AI extract soal dari PDF.

Anthropic API key

Dipakai hanya untuk fitur "Import PDF dengan AI" di halaman Bank Soal. Key ini disimpan di browser kamu saja (localStorage), tidak dikirim ke server mana pun selain langsung ke Anthropic. Kalau tidak diisi, kamu tetap bisa memakai input manual atau import .md tanpa AI sama sekali. Dapatkan key di console.anthropic.com.

Password admin

Password admin diatur lewat file js/config.js di kode sumber, bukan dari halaman ini — supaya tidak bisa diubah orang lain lewat browser. Ubah nilai ADMIN_PASSWORD di sana lalu deploy ulang kalau ingin menggantinya.
